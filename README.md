# Moo Camera

Android camera app for the Oppo Find N5: always opens on the rear camera, natural beauty look, viewfinder on the cover screen so the rear camera is the selfie camera, palm timer.

**Download the latest build:** <https://github.com/moosolutionsAI/moo-camera-releases/releases/latest/download/moo-camera.apk>

Page: <https://moosolutionsai.github.io/moo-camera-releases/>

Install over the previous version (same signing key). If Android asks, allow your browser to install apps. The app checks this repo for new versions and shows an "Update" pill when there is one.
